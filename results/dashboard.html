METHODOLOGY

What these results mean

01 · Same workloads

Schedulers are compared on the same held-out workloads to make the comparison fair.

02 · Unseen test seeds

The reported evaluation uses 100 unseen workloads per scenario, separate from training seeds.

03 · Statistical check

Paired permutation testing and Holm correction are reported for multiple comparisons.

04 · Honest baseline

SJF is a reference ceiling because it assumes burst times are known in advance.

This dashboard presents saved outputs. It does not run the scheduler or retrain the Q-learning agent in the browser.
